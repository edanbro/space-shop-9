# Space Shop 9

A VR shop on the Moon, built by a team of five Maynooth University students in April 2025. You walk
around a shop on the lunar surface and pick items up off the shelves.

Built with Godot 4.4 and OpenXR, using [Godot XR Tools](https://github.com/GodotVR/godot-xr-tools)
for movement and grabbing.

## My part

- Set up the Godot project, with the main scene and the player scene.
- VR movement for the player.
- Made the shop's items pickable in VR.
- Organised the assets into one folder.
- Merged teammates' pull requests.

The 3D models, textures and the Moon scene came from teammates.

## Run it

Open the folder in Godot 4.4 and run the main scene (`scenes/main.tscn`) with an OpenXR headset
connected.
